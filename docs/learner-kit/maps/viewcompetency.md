# Field map — `TRK` · Competency Tracker (`view-competency.php`)

"Competency Tracker" mode: a grid of the courses linked to one competency of a plan.
Renderable `view_competency_page` → `view_competency.mustache`: hero, a toolbar (completion
tabs + Filter button), the hidden chip panel and the card grid. Each card's progress body
loads over AJAX (`competency_view.js` → `get_course_progress` → `progress_card_body.mustache`),
preceded by a lightweight `get_courses_completion_status` batch that tags each card, fills the
completion tabs and orders the loader. Visual replica: `screens/trk-tracker.html`,
`screens/trk-card-states.html`, `screens/trk-locked.html`, `screens/trk-empty.html`
(+ shared `screens/hero.html`, `screens/chips.html`).

**Settings affecting this screen:** `percentagedisplaymode` (**fixed / hover (default) / hidden**),
`lockedcardmode` (blocked/learnmore), `showlockeddate`, `cardicon`, `learnmorebuttoncolor`,
`animatelockedborder`, `enablecustomscss`, `viewcompetency_filter_fields_course`. Cascade
`enrollmentfilter` + `singlecourseredirect` (redirects when exactly one accessible course
remains, unless `noredirect=1`). Course order is fixed server-side, `ORDER BY c.startdate ASC`
(`view-competency.php:83`).
