The dialog is a large core/modal; its body is emptied and refilled with the pager plus a clone of the item's accordion body, so paging never destroys and rebuilds the dialog (a destroy/create pair plays the close and open animations back to back, which reads as a flash). Because the modal is appended to document.body, outside the plan wrapper, the body re-applies the percentagemode-* class by hand. The tab strip is not the modal's own — it is whatever buildSummaryTabs renders into the cloned shell.
