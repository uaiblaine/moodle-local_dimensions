The trigger is the course's format, not a count on its own: calculator::resolve_card_shape() lands here first when the format is Moodle's own singleactivity (mirroring format_singleactivity::get_main_activity() — the format option's activitytype, section 0 only, first module of that type), and only as a fallback, for any other format, when the course happens to resolve to exactly one trackable, visible module. Either way there is no sequence to draw. One activity can only be 0% or 100%, so this shape gets a check or circle, never a ring. The right-hand card is that same body with the activity's completion tracking switched off: activity.tracked is false, so the marker and the "Completed" / "Not completed" text are both dropped — the card still names the activity and links to it, the case that used to show nothing at all. This body sits outside the {{#enabled}} guard on purpose, so it survives course-level completion tracking being off.

Third match of resolve_card_shape(): the course has exactly one qualifying section (not delegated to a subsection, visible, and either user-visible or carrying availability text — the same filter the timeline itself applies; an empty section still qualifies, deliberately). A one-row timeline naming a section usually called "General" or "Topic 1" would inform nobody, so the card shows the section's own percentage as a ring — the timeline's own ring component reused at the size of the single-activity card's state marker (56 px), so both compact bodies read as one shape — and the section's name only when a teacher authored one (Moodle stores NULL for a generated label). A section with nothing trackable drops the ring entirely rather than claiming a misleading 0%; the name and the call to action survive either way. The call to action is the neutral "Access content", landing on /course/section.php?id=…. Note what this body does not carry: unlike the activity body, it has no status text, and the completed seal lives inside {{#istimeline}} — so a completed course resolved to this shape shows no completion signal at all.
