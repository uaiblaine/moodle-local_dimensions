The description leads and can be long, rich HTML or an embedded video — it is the competency's raw description passed through unaltered. One column: there is no taxonomy aside card and no boxed breadcrumb at the top. The path and the taxonomy share a single low-contrast footnote line, each half gated independently, and the row renders whenever at least one of them has something to say. The taxonomy is a <button>, not a label — pressing it opens a modal with that taxonomy type's definition.
Both footnote halves are optional

showtaxonomycard off, or the taxonomy key has no definition string: only the trail renders.
showpath off, or the competency has neither a framework shortname nor a parent: only the taxonomy button renders. With both halves empty the footnote returns an empty string, and the whole Description tab disappears unless the description, the taxonomy or a relation keeps it alive.
