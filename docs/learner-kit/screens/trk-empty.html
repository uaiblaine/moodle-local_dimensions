One shared element for both: a 56 px icon chip, a title and a muted note, centred, role="status" on both states — the not-found one is not an alert, it only swaps the chip to the amber warning variant. The chips are FontAwesome (fa-graduation-cap / fa-exclamation-triangle); the SVGs above stand in for them so this preview needs no icon font. The two are mutually exclusive: a missing competency also yields empty courses, but the no-courses state is gated inside hascompetency, so only the warning shows. The same .local-dimensions-empty pattern serves the plan overview — see ovw-empty.
