Points rule, in progress · OVW-RULES-SENTENCE
How it is earned

Once the sum of points reaches the required value, will be automatically validated and marked as complete.

Pay attention to required items.

Progress 45 / 60 pts
4 items in total
The sentence is the answer the learner came for, so it leads the pane in plain prose — no boxed aside, no info icon. Its text is the server-composed outcometext, picked from the six rules_{points,all}_outcome_{complete,recommend,attach} strings by rule type and outcome. The required-items caveat sits under it as a second line, in orange, whenever the rule has any required child. Below it, progress is deliberately quiet: label and score at the same 0.875rem muted weight, then a 6px flat bar. No big number, no gradient, and no warning triangle — the missing-mandatory notice below says that in words, and two alarms for one condition read as two problems.
All / Required filter — only when the rule has required children OVW-RULES-FILTER
The same platter component the plan toolbar uses. It filters in place: “Required” sets hidden on every card whose data-required is not true, so nothing is refetched and the progress figures above never move.

Every child in the rule is listed, in rule order, including the ones still to do — the list is the rule’s own arithmetic made visible, so removing rows from it would make the score above unexplainable. The three status marks are real image assets (pix/status/rules-{proficient,inprogress,todo}.svg), each with an sr-only label; the middle one is an open orange ring, not a part-filled dial, and “to do” is a grey ellipsis rather than a dashed outline. Points render only for points rules; an all-or-nothing rule shows the same rows with the points column omitted and counts completed children instead.

Same bar, same weight — only the context line under it changes, from the muted item count to an orange sentence. The bar is not striped and no triangle appears beside the label; both were removed deliberately. The pending required child is marked by a soft orange border on its whole card, which is also what an ordinary required child carries, so the alert line is what actually distinguishes this state.
