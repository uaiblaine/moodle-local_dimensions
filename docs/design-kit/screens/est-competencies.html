The curtain covers the content that is already in the pane — it does not replace it, and it has no text: .local-dimensions-central-tab-loading (styles.css:4340-4343, with min-height: var(--mds-loading-min-height) = 12rem, defined at :34, so the pane does not collapse behind it) + a ::before veil of rgba(255,255,255,0.55) (:4033-4042) + a ::after ring of 2rem in #0f6cbf (:4044-4057), animated by @keyframes local-dimensions-central-spin (:4059-4063) and slowed to 1500ms under prefers-reduced-motion (:4065-4069). The ring above really does spin and the aria-busy="true" is on this element. Measured caveat: the veil is a fixed white — there is no dark-scheme variant in styles.css (the only occurrence of rgba(255, 255, 255, 0.55) is the one at :4041).
Scope: the curtain does not enter the tab switch — that already has loading, from core (core/dynamic_tabs: loadTab → addIconToContainer, and the previous pane is emptied first). The gap that was filled is the plugin's reloadPane (tabs.js:69-108), which redid loadTab's path without that icon — and it is the one that runs at the 24 call sites across 5 modules. It now adds LOADING_CLASS (:44) + aria-busy (:78-79) and clears them in a finally (:100-106), guarded by a monotonic per-pane generation counter (:74-75) so a stale reload cannot switch off a newer one.

The house rule, and how it is actually met. Pane reloaded → curtain; row swapped → flash (flash.js:41-43 reads the duration from the --mds-motion-flash token = 1500ms, styles.css:22). refreshNode (structure.js:726-786) is the deliberate in-place path: in the stretch that swaps the row (:756-786) it does not call reloadPane — so there is no curtain there because there is no reload, not because of an opt-out. It falls back to reloadPane (with a curtain) only at the four detours: node missing (:730), node with no data (:739), node reparented during the edit (:748, followed by revealNode at :751) and a render failure (:764). persistRule (:848) and updateCourseCount (:909) confirm with a flash (:876 and :920); applyShowHidden (:272-291) rebuilds the select's options with no reload and with no flash — there is no visual confirmation on that path. The explicit opt-out {quiet: true} exists (tabs.js:69, :77, :103) and has exactly one caller: reloadKeepingScroll (plans.js:94-110, called at :102), which is a real pane reload that preserves scrollTop.
