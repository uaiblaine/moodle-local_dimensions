How it was measured. getAnimations().forEach(a => a.cancel()) before reading (a frozen transition returns the previous theme's colour); the 140deg gradient was rebuilt in a <canvas> with the header's real geometry and sampled at the pixel at the button's centre (584, 36 — the button sits 18px from the right in a 620px dialog, so it falls well past the 48% stop); the rgba(255,255,255,0.16) glass was composited over that sample. Measuring against the .cx "as is" would return the transparent parent and a false number. The fill itself comes out at 1.50–1.65:1 against the gradient — below 3:1 — but what identifies the control is the glyph, and it carries the table's ratio.
