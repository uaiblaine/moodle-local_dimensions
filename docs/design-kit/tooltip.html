The rule at styles.css:7426-7434 lists three triggers on the wrapper — :hover, :focus-visible and :focus-within. Only the first fires today: both shipped instances wrap a plain <span>, and a span does not get a tabindex just so a balloon can open (see rule 2). Clipped
ancestor with overflow: hidden
Known limit, and the reason the variant exists. Any ancestor whose overflow is not visible clips the balloon — and overflow-x:auto forces the Y axis to auto too, so horizontal scrolling clips top and bottom alike. In the plan accordion this is not hypothetical: .local-dimensions-accordion-item (styles.css:1448-1457) and .local-dimensions-accordion-content (:1587-1592) both set overflow: hidden for the expand/collapse, and both tooltips sit near the top of a pane — which is why both shipped instances carry .local-dimensions-tip-bottom. There is no auto-detection: choosing at authoring time is cheaper than shipping a positioner. A balloon that needs to escape its container is a sign the information should be visible, not on hover.

Design System rules — tooltip

  1. Never the only carrier of the information. The tooltip accompanies text that is already in the DOM and was clipped visually — both call sites print the same string twice, once in the clipped child and once in data-dim-tip. If the value existed only in the balloon it would be invisible to screen readers, to touch and in print — in that case, show it.
  2. No ARIA and no tabindex for the balloon's sake. Because nothing is hidden from assistive technology the balloon is decoration: no role="tooltip", no aria-describedby, no Esc handler — and the shipped markup has none of them. Adding tabindex="0" to a <span> just to make it focusable creates tab stops through a long list — do not. When the target is already a control, :focus-within covers it for free.
  3. Never pair it with title. The native balloon would sit on top of ours, on its own delay and in the operating system's styling. One or the other — title stays valid on a lone informational icon, like the "No completion tracking" marker in the tracker timeline (progress_card_body.mustache:288, an img with alt="" + aria-hidden + title), which carries no .local-dimensions-tip.
  4. Clip on the child, balloon on the wrapper. .local-dimensions-tip carries no overflow; the clipped children carry no position: relative.
  5. Order in the stylesheet is load-bearing. .local-dimensions-tip-bottom must stay after the base ::after/::before rules: same specificity, so if it moves up the base rules re-apply bottom and border-top-color and over-constrain the box. The shipped CSS says so in a comment at styles.css:7408-7412.
  6. Short text. The balloon qualifies a label; it does not host a paragraph, a link or markup — content: attr() renders plain text by definition. An explanation that needs a link or a list is a modal, like "About this scale" (accordion.js:1371-1387, string scale_about).
