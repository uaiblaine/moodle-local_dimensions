# Comment audit of the production code, 2026-11-17

Scope: the 182 production files (`classes/`, `amd/src/`, `templates/`, `db/`, the top-level `*.php`
and `styles.css`) changed between `c33c1a5` (the previous audit, 2026-09-23) and `8de9204`. The
round reviewed the comments added or changed since then, plus older comments over changed code.
Tests, `js/esm/src` and the docs were out of scope (a later round).

Method: `moodle-dev/ci/comment-audit` (rubric, `check.py`), run as subagents rather than a
workflow: 9 batches, one Opus rewriter and one Sonnet verifier each, one Sonnet refuter per bug or
risk finding.

## Result

- 51 source files edited, comments only (`check.py`: 0 problems), plus the regenerated `amd/build`
  source maps and `filter_line.min.js` (its file docblock ships). 61 comments corrected because
  they contradicted the code, for example:
  - `reportbuilder/local/helpers/link.php` said `PARAM_URL` accepts `mailto:`; core rejects it and
    accepts scheme-less paths.
  - `reportbuilder/local/entities/template.php`: the plan count covers only plans still linked to
    the template (core clears `templateid` on unlink).
  - `helper.php`: `sync_enrollmentfilter_option()` is not called on every upgrade;
    `legacy_repair` runs it once per site.
  - `local/csv_formula.php`: core's spreadsheet-formula escape exists on 5.3; the reason the plugin
    keeps its own is the `unescape()` counterpart core lacks.
  - `filter_line.js`: it shares only the matching rule and the suggestion ranking with
    `theme_dimensions`' filter line, not its folding steps or hooks.
- References to the development environment and its process (the filter-line and course-card
  contract documents in `moodle-dev`, decision ids, "the fleet") were removed. The repo `CLAUDE.md`
  still names both contracts, so nothing a maintainer needs is lost.

## For the owner: improvements and questions (not changed)

Improvements, each judged plausible by its batch verifier:

- `external/get_courses_completion_status.php:132` catches `\Exception` per course while its sibling
  `get_course_progress.php` catches `\Throwable`: a `TypeError` in one course fails the whole response.
- `chip_filters.php:285` `display_value()` re-implements `helper::split_select_options()`.
- `external/get_user_competency_summary_in_plan.php:111` reads the plan a second time for its owner.
- `local/template_csv_serializer.php:204` re-checks an unreadable framework for every competency.
- `reportbuilder/local/entities/user_evidence.php:79` file count subquery omits `contextid`, so it
  cannot use the full files index.
- `db/install.php:40` and `legacy_repair::run()` both call `ensure_unaccent()` on install.
- `calculator.php:978` `current_user_has_pending_application()` has no production caller left.
- `amd/src/central/context.js:393` the tab listener no longer needs jQuery.
- `amd/src/central/delete_check.js:49` builds lang string ids dynamically, which
  `lang_string_references_test` cannot see.
- `@copyright` carries an e-mail address in nine files (`db/caches.php`, `db/hooks.php`,
  `settings.php`, `classes/constants.php`, `classes/hook_callbacks.php`, `classes/scss_manager.php`,
  `classes/template_course_cache.php`, both customfield handlers); the fleet header has none.

Questions:

  `$plugin->supported`'s minimum reaches 503, which it now has on `main`. Drop it (with
  `colour_tokens_test::test_media_fallback_is_written_and_unreachable` and
  `colour_mode::MEDIA_OPTIN_ATTRIBUTE`) or keep it for clean cherry-picks?
- `styles.css:6094` and nearby: Moodle 4.5 / Bootstrap 4 fallbacks are still on `main`, against the
  repo `CLAUDE.md` rule that only `MOODLE_405_STABLE` carries 4.5 code. Same choice.
- `amd/src/learner_prefs.js:45`: the 1333-character favourites cap only binds on Moodle 4.5.

  skips `can_delete_full()` can fail on a child after the parent's contents are gone.
- `template_metadata_cache.php:429`: the cached and the live enrolment-filter decoders treat an
  option index past the last option differently.

Not verified (kept as written): `styles.css:1657` (Chromium before 120 reads only the `-webkit-`
